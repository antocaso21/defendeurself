# DefendEUrself static website

Responsive, accessible multi-page HTML/CSS/JavaScript website using the same information architecture as the reference HikeWise project website:

- Home
- About
- Results
- Blog
- Newsletters
- Contact

## Preview
Open `index.html` in a browser.

## Before publication
1. Replace or confirm project social-media links.
2. Connect the newsletter and contact forms to a backend or form service.
3. Add official PDF files to `/downloads` and replace `data-coming-soon` buttons with real URLs.
4. Replace the vector project wordmark with the official DefendEUrself logo, if available.
5. Confirm any final project contact email and social channels.

The site uses no external scripts, fonts or image services. All illustrations are local SVG files.
